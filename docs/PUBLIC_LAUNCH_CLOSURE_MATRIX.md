# CatchGrid public-launch closure matrix

**Reviewed:** August 13, 2026

**Source audit:** [`docs/PUBLIC_LAUNCH_AUDIT.md`](PUBLIC_LAUNCH_AUDIT.md)
**Working catalog:** `2026-08-13.1`

This matrix accounts for every P0 and P1 finding in the source audit. Statuses describe the
current working tree, not the currently deployed site:

- `fixed` means the implementation and cited local evidence are present in the working tree.
- `open` means required implementation, automated evidence, or release verification is still
  missing.
- `externally blocked` means completion requires evidence, permission, or measurement that
  cannot be produced from the repository alone.
- `deliberately deferred` means the work must remain pending for a documented timing or migration
  reason.

The release is still **no-go**. A real isolated staging D1 is now configured, but staging has not
yet been migrated, deployed, or smoke-tested. Public `main`, production, operational controls,
and the external evidence below also remain unverified against this working tree. A source-level
`fixed` status must therefore not be read as proof that the change is live.

## Remaining release gates

The matrix leaves five findings open, three externally blocked, and two deliberately deferred.
Before changing the recommendation to go, the release owner must at minimum:

1. add automated legacy-origin messaging coverage and verify the old live origin before any
   redirect or retirement;
2. merge the reviewed source to protected `main`, require the five documented checks, and identify
   the exact release SHA;
3. migrate, deploy, and smoke-test the isolated staging Worker/D1 with its separate secret;
4. capture a production Time Travel bookmark, rehearse rollback, and configure/evidence Cloudflare
   alerts plus cache/D1 measurements;
5. obtain an accepted asset-rights position, manual VoiceOver/accessibility evidence, and real
   production Core Web Vitals; and
6. run production smoke, header, CSP, PWA, catalog-version, and exact-SHA checks only after the
   reviewed commit is deployed.
