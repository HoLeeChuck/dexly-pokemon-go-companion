## September 26, 2026 — data dashboard direction (local, uncommitted)

The user found the Pokédex scanner not innovative enough for the audience: data-minded players who today keep a spreadsheet (have / don’t have per category) and turn it into a search string. New direction, approved from an inline concept: Apple design principles, fast data entry, satisfying progress. **Home = dashboard, Progress = collection grid, click a Pokémon for details.** The Dex tab (shelf/scanner) stays for now; the user will decide its future.

- **Home dashboard:** large-title hero with overall % across all eight categories; eight Apple-Watch-style rings (one Apple system colour per category, used consistently); region × category heatmap (cells link to Progress filtered to that region, category and missing); 30-day activity chart with week, month and streak (from `updatedAt`, recorded since September 25) and the recap card; almost complete; medals; poster and compare link (moved from Progress); next legacy move; backup; link to the Pokédex.
- **Progress grid:** one row per Pokémon, one column per category, like the spreadsheets users keep. Sticky header row (per-column count and bar; clicking a header sets the category for the string and filter) and sticky name column inside a scrolling panel; per-row done count. Click toggles a cell; drag down/across or Shift-click fills a range in one save with snapshot and Undo; arrows move (skipping ineligible cells), Space/Enter toggles, one tab stop. Region/forms/search/All-Missing-Have filters; pages of 100 via a “Showing” dropdown when the list is long. Ineligible cells show “–”.
- **Live search string panel:** category, None/Personal/Tradeable prefix, the exact `missingSearch()` output (same as Search Lab), missing count and character count, copy, link to Search Lab. Sticky beside the grid on desktop.
- **Details:** clicking a name opens the existing details dialog over the grid (now with the same chip-style toggles as the scanner). Viewing never toggles ownership.
- **Removed:** the Progress collection map, depth view and paint mode (the grid’s drag-fill replaces paint mode), the old Home recap block (folded into Activity).
